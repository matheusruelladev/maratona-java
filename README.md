# Maratona Java — DevDojo

Repositório dedicado aos meus estudos de Java por meio da Maratona Java, do DevDojo.

O objetivo deste repositório é documentar minha evolução no aprendizado da linguagem Java, armazenando exercícios, exemplos práticos e experimentos desenvolvidos durante as aulas.

Este espaço também serve como laboratório para praticar Git e GitHub, organização de código e controle de versão.

## 🎯 Objetivos

- Desenvolver uma base sólida na linguagem Java.
- Praticar lógica de programação e resolução de problemas.
- Compreender os fundamentos da programação orientada a objetos.
- Registrar minha evolução e acompanhar meu progresso.
- Praticar Git e GitHub durante o processo de aprendizagem.

## 🛠️ Tecnologias e ferramentas

- Java 17
- Visual Studio Code

- Git
- GitHub

## 📁 Estrutura do projeto

```text
DevDojo/
├── src/
│   ├── App.java
│   └── academy/
│       └── devdojo/
│           └── maratonajava/
│               ├── core/
│               └── introducao/
├── lib/
├── .gitignore
└── README.md
```

- `src/`: códigos-fonte e exercícios Java.
- `lib/`: diretório destinado a bibliotecas externas.
- `bin/`: arquivos compilados, mantidos localmente e ignorados pelo Git.

## ▶️ Como executar

1. Instale o JDK 17 ou uma versão compatível.
2. Instale o Visual Studio Code.
3. Instale a extensão Extension Pack for Java.
4. Clone este repositório:

```bash
git clone git@github.com:matheusruelladev/maratona-java.git
```

5. Abra a pasta do projeto no Visual Studio Code.
6. Navegue até o exercício desejado e execute a classe Java.
